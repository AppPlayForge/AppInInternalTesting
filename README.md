# 升了麽

### 老齡人士安全提醒 App

針對老齡人士設計，在倒計時結束後，如果使用者沒有完成打卡，App 可以自動發送求助通知。

同時提供自定義計時器。如果使用者未在指定時間內完成打卡，可以自動發送：

- 電子郵件
- 簡訊
- 電話

# keedChat

### 加密通訊

不需要手機號碼或電子郵件地址即可註冊，注重使用者隱私。

支持：

- 加密文字訊息
- 圖片
- 影片
- 定位資訊
- 視頻通話
- 群組聊天

目前為測試版，仍存在許多 Bug。

如果遇到問題，請提交相關日誌，以協助改進 App。
