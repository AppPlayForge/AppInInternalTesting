# 升了麽

### Application de sécurité pour les personnes âgées

Conçue pour les personnes âgées, l'application peut envoyer automatiquement une alerte SOS si l'utilisateur ne confirme pas sa présence avant la fin du compte à rebours.

Elle propose également un minuteur personnalisable. Si l'utilisateur ne confirme pas sa présence dans le délai défini, l'application peut automatiquement envoyer :

- un e-mail ;
- un SMS ;
- un appel téléphonique.

# keedChat

### Communication chiffrée

L'inscription ne nécessite ni numéro de téléphone ni adresse e-mail, afin de protéger la vie privée des utilisateurs.

Fonctionnalités :

- Messages texte chiffrés
- Images
- Vidéos
- Partage de localisation
- Appels vidéo
- Discussions de groupe

Il s'agit actuellement d'une version bêta qui contient encore de nombreux bugs.

En cas de problème, veuillez soumettre les journaux correspondants afin de contribuer à l'amélioration de l'application.
