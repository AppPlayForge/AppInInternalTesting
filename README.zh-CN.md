# 升了麽

### 老年人安全提醒 App

针对老年人设计，如果用户在倒计时结束前没有完成打卡，App 可以自动发送求助通知。

同时提供自定义计时器。如果用户未在指定时间内完成打卡，可以自动发送：

- 电子邮件
- 短信
- 电话

# keedChat

### 加密通讯

注册不需要手机号码或电子邮件地址，注重保护用户隐私。

支持：

- 加密文字消息
- 图片
- 视频
- 位置共享
- 视频通话
- 群组聊天

目前为测试版，仍存在许多 Bug。

如果遇到问题，请提交相关日志，以帮助改进 App。
