# 升了麽

### 高齢者向け安全確認アプリ

高齢者向けに設計されており、カウントダウン終了までにチェックインが行われなかった場合、自動的にSOS通知を送信できます。

カスタマイズ可能なタイマーにも対応しています。指定時間内にチェックインできなかった場合、以下を自動送信できます。

- メール
- SMS
- 電話

# keedChat

### 暗号化通信

電話番号やメールアドレスを必要とせずに登録でき、ユーザーのプライバシーを重視しています。

以下の機能に対応しています。
- 暗号化テキストメッセージ
- 画像
- 動画
- 位置情報
- ビデオ通話
- グループチャット

現在はベータ版のため、多くのバグが残っています。

問題が発生した場合は、関連するログを送信していただけると改善に役立ちます。
