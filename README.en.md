# 升了麽

### Senior Safety App

Designed for seniors, the app can automatically send an SOS notification if the user fails to check in before the countdown ends.

It also provides a customizable timer. If the user fails to check in within the specified time, the app can automatically send:

- Email
- SMS
- Phone call

# keedChat

### Encrypted Communication

Registration does not require a phone number or email address, with a focus on user privacy.

Features include:

- Encrypted text messages
- Images
- Videos
- Location sharing
- Video calls
- Group chats

This is currently a beta version and still contains many bugs.

If you encounter problems, please submit the relevant logs to help improve the app.
